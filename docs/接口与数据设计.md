# 接口与数据设计

所有业务接口使用 /api 前缀。成功返回 JSON 或空响应，错误返回 `{ "message": "可读说明" }`，并使用 400 / 401 / 403 / 404 / 409 / 413 / 429 / 500 状态码。列表返回 `{ items, total, page, size }`，页码从 1 开始，单页最多 100 条。

## 认证

- GET /auth/csrf：取得 token、headerName，并建立服务端会话。
- POST /auth/login：提交 username、password；登录成功更换会话，重新请求 CSRF。
- GET /auth/me：当前管理员（不返回密码哈希）。
- POST /auth/logout：注销会话。
- POST /auth/password：oldPassword、newPassword，成功后需重新登录。

写请求包含上一步 headerName 指定的 CSRF 请求头。前端不保存密码或会话令牌到 localStorage，Cookie HttpOnly、SameSite=Lax，生产启用 Secure。登录尝试按账号及来源限制，窗口 15 分钟；限流状态在进程内，重启会清空，单实例范围内使用。

## 公开查询

- GET /public/contents?type=NEWS&page=1&size=12&category=新闻动态：只查询 PUBLISHED。
- GET /public/contents/{id}：独立内容详情，草稿、回收站与下架返回 404。
- GET /public/pages/home、about、join：固定页面。
- GET /media/{id}：仅管理员或已发布内容引用的图片可以读取；不缓存。

## 内容管理（两类管理员）

- GET /admin/contents：type / status / category / page / size；不传 status 时排除回收站。
- GET /admin/contents/{id}：读取草稿、预览及编辑。
- POST /admin/contents：创建草稿。
- PUT /admin/contents/{id}：保存字段；需携带当前 version，成功后返回递增版本。
- POST /admin/contents/{id}/publish：发布。
- POST /admin/contents/{id}/unpublish：下架为草稿。
- POST /admin/contents/{id}/trash：回收站。
- POST /admin/contents/{id}/restore：恢复为草稿。
- POST /admin/media：multipart/form-data，file 字段；返回 id、url、原始文件名、大小、类型。
- GET /admin/audit?page=1&size=20：操作人、操作、对象编号与时间。

状态操作提交 `{ "version": 0 }`。保存内容提交：

```json
{
  "type": "ACTIVITY",
  "title": "待补充",
  "category": "活动预告",
  "summary": "待补充",
  "body": "<p>待补充</p>",
  "coverId": null,
  "metadata": { "location": "待补充", "gallery": [] },
  "sortOrder": 0,
  "featured": false,
  "pinned": false,
  "archived": false,
  "version": 0
}
```

内容类型：NEWS、ACTIVITY、PROJECT、PERSON、PAGE。PAGE 仅允许修改预置固定页面，禁止新建及删除。metadata 写入为对象，响应中的 metadata 为序列化 JSON 字符串（前端 api.ts 的 meta 统一解析），字段如下：

| 字段 | 用途 |
| --- | --- |
| startAt / endAt | 活动时间，ISO 本地日期时间，例如 2026-11-09T14:00 |
| location / activityStatus | 活动地点与状态 |
| members / repository / demo | 项目成员、仓库、演示链接 |
| sourceName / sourceUrl / credit | 原文来源、链接与图片署名 |
| cohort / position | 成员届别与身份 |
| gallery | 图片 ID 数组，最多 40 张 |
| joinUrl | 外部报名链接 |

链接只允许绝对 HTTP/HTTPS 地址。富文本使用 Jsoup 白名单清洗；图片 src 仅接受本站 /api/media/{id}。

## 账号管理（仅超级管理员）

- GET /admin/accounts：账号列表。
- POST /admin/accounts：username、password、role（ADMIN / SUPER_ADMIN）。
- PUT /admin/accounts/{id}：enabled、role。
- POST /admin/accounts/{id}/password：password，重置密码并撤销旧会话。

## 数据表

- admin_account：个人账号、BCrypt 哈希、角色、启用状态、认证版本。
- content：统一内容、发布状态、封面、扩展信息、排序、首页标志、归档、乐观锁版本、时间。
- media_file：服务端 UUID 文件名、原始名称、类型、大小。
- content_media：封面 / 正文 / 相册引用关系，用于公开读取鉴权，带数据库外键。
- audit_log：操作人、动作、对象编号、时间。无后台删除接口。

保存正文、图片引用、发布状态和操作日志使用同一数据库事务。图片二进制位于持久化上传目录。上传后尚未保存引用的文件保留为私有文件；第一版不提供自动删除孤立文件的任务，以免误删正在编辑的资料。长期运营时可在备份后增加延迟清理机制。
