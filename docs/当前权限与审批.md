# 当前权限与审批（2026-11-10）

本文件记录已失效的中间版本权限约定，包含本轮新增的超级管理员账号管理、操作记录查询和固定页面纯文字修改。

登录、查询当前身份、退出、填写草稿时上传并查看自己的图片属于必要基础功能。公开内容查询继续向所有访客开放。

## 操作流程

1. 两种角色在内容管理页选择“新建内容草稿”，填写新闻、活动、项目或师生资料，上传封面/正文/相册图片。
2. 提交后固定为 DRAFT，不能修改或删除，普通管理员不能查询待审批列表。
3. 超级管理员的后台展示所有 NEWS、ACTIVITY、PROJECT、PERSON 类型的 DRAFT，不受提交人限制。
4. 超级管理员点击“查看并审批”，阅读只读全文后点击“审批通过并发布”。通过后变成 PUBLISHED，出现在官网。
5. 未通过审批的内容保持草稿且不公开；没有增加驳回、退回修改或删除功能。

超级管理员可在“账号管理”中创建账号、启用或停用其他账号、调整角色、重置本人或其他账号的密码；不能停用或降级自己。账号不提供永久删除和用户名更改。密码或角色修改后旧会话在下一次请求时失效；重置本人密码后需重新登录。首次超级管理员仍由部署时 BOOTSTRAP_USER/BOOTSTRAP_PASSWORD 创建。新建和重置密码沿用当前项目 5–72 字符要求。普通管理员没有账号管理和密码修改权限。

## 仍可访问的管理接口

- POST /api/admin/contents：两种角色创建草稿，type 仅 NEWS/ACTIVITY/PROJECT/PERSON。
- POST /api/admin/media：两种角色上传草稿图片。
- GET /api/admin/contents：仅超级管理员查询待审批草稿，支持 type/page/size；传入旧 status 参数不能查询其他状态。
- GET /api/admin/contents/{id}：仅超级管理员读取待审批草稿。
- POST /api/admin/contents/{id}/approve：仅超级管理员审批，正文为版本对象，例如 {"version":0}。

旧 PUT 内容修改、publish/unpublish/trash/restore 以及 /api/auth/password 仍不开放。账号密码通过仅超级管理员可用的 /api/admin/accounts/{id}/password 管理。通过 URL 或直接 HTTP 请求也无法绕过。

新建草稿沿用原 Input 结构，sortOrder 必须为 0，featured/pinned/archived 必须为 false，version 必须为 0。服务端同时校验，不能通过伪造请求设置这些权限字段。审批只改变发布状态和时间，不允许顺带修改标题、正文或其他内容。

## 数据迁移与已有数据

新增 V2__draft_submission_ownership.sql，只增加 content.created_by 和 media_file.uploaded_by，不改动已执行的 V1，也不清空账号和内容。重启正式后端时由 Flyway 执行。

旧草稿没有提交人记录，界面显示“历史草稿（提交人未记录）”，超级管理员仍可审批四种允许类型的旧草稿。旧固定页面、已发布内容保持原状，旧回收站内容不进入审批列表，不再提供恢复。

图片访问规则：匿名只能读取已发布内容引用的图片；登录者额外可读取自己上传的图片；超级管理员额外可读取允许类型的待审批草稿引用图片。新草稿只能引用自己上传或已公开的图片，不能借引用猜测他人的私有图片。

## 新增超级管理员接口与固定页面文字

- GET/POST /api/admin/accounts：查询和创建账号。
- PUT /api/admin/accounts/{id}：更改 enabled/role。
- POST /api/admin/accounts/{id}/password：重置密码；更新认证版本，撤销原会话。
- GET /api/admin/audit?page=1&size=20：只读查询操作记录。
- GET /api/admin/pages：读取 home/about/join 的标题、摘要和正文文字片段。
- PUT /api/admin/pages/{id}/text：仅接收 title、summary、bodyTexts、version。额外字段返回 400；版本冲突返回 409。

固定页面使用现有正文的文字节点逐段编辑，不提供富文本或 HTML 编辑入口。保存时通过 TextNode 设置文字，输入的 HTML 会被转义。既有标签、图片、链接目标、封面、metadata、分类、发布状态、推荐/排序等字段均不能修改。页面文字保存后立即反映到公开官网，不需要额外发布。修改操作会写入 UPDATE_PAGE_TEXT 日志。

本轮没有新增数据库迁移；已有 V1/V2 保持不变。后端 7 组测试通过、前端生产构建通过。新增验证覆盖普通管理员被拒绝、超级管理员账号管理、角色变更和密码重置撤销会话、固定页面额外字段拒绝、链接图片保留、HTML 转义、版本冲突及禁止修改非固定内容。
