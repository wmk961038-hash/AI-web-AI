# 恢复第一版功能（2026-11-10）

本轮依据最初实现记录恢复第一版功能和权限。没有找到独立的第一版源码快照，因此这是功能恢复，不是逐字节还原历史文件。恢复前的源码备份路径记录在 .cache/first-version-restore-backup.txt。

取消中间版本的“仅提交草稿、超级管理员审批”限制。所有管理员可直接发布；没有独立审批入口。固定页面不再只限文字，恢复完整正文、封面和链接维护。固定页面不能新建或移入回收站；已发布内容保存修改后立即更新官网。

## 接口恢复

- GET /api/admin/contents：type/status/category/page/size 查询；默认排除回收站。
- GET /api/admin/contents/{id}：任意管理员读取详情或预览。
- POST /api/admin/contents：新建草稿。
- PUT /api/admin/contents/{id}：保存内容，需 version。
- POST /api/admin/contents/{id}/publish、unpublish、trash、restore：对应状态操作，需 version。
- POST /api/auth/password：oldPassword/newPassword，两种角色均可修改自己的密码。
- GET /api/admin/audit：两种角色均可只读查询。
- /api/admin/accounts：仅超级管理员查询/创建账号；PUT /{id} 调整状态角色；POST /{id}/password 重置密码。

删除中间版本的 /api/admin/pages、/{id}/text 专用接口及纯文字编辑面板，固定页面统一通过内容编辑器维护。/approve 不再是支持的状态操作。

## 数据与运行

未连接或修改现有 MySQL 数据。保留 V1 和 V2 迁移以及 created_by/uploaded_by 字段，避免破坏已有迁移历史或内容。管理员恢复对全部私有图片的编辑访问，匿名访客仍只能读取已发布内容引用的图片。

现有账号、密码、已发布内容、草稿和回收站状态保持。新建或重置密码、修改自己的密码恢复第一版 12–72 字符要求；已存在的较短密码仍可登录，首次创建超级管理员也要求 12–72 字符。

重启 IDEA 中的 ClubApplication，前端开发服务器保存后自动刷新，必要时手动刷新浏览器；无需删表或修改数据库密码。若使用 Docker，请重新构建前后端镜像。

保留此前已经验证的 CSRF、防止会话固定、密码哈希、会话撤销、富文本清洗、图片校验、版本冲突检测和 wangEditor 事件清理修复；不回退依赖安全补丁。
