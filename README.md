# 人工智能社官网

## 项目定位

建设一套可运行、适配电脑与手机、方便长期维护和迭代的人工智能社官网。网站重点展示社团的竞赛、科研和技术项目，同时支持管理员通过后台持续更新内容。

本文档为第一版功能规划与验收依据，不代表相关功能已经实现。

## 一、用户与访问方式

第一版面向两类使用者：无需登录即可浏览的访客，以及通过账号密码登录后维护内容的管理员。第一版不开放普通用户注册。

### 访问入口

| 入口 | 访问方式与行为 |
| --- | --- |
| 官网首页 `/` | 打开网站直接展示公开首页，无需登录 |
| 登录页 `/login` | 提供管理员账号密码登录，以及“浏览官网”按钮 |
| 管理后台 `/admin` | 仅管理员登录后可访问；未登录时跳转登录页 |
| 新闻、活动和项目详情页 | 提供独立地址，可直接访问和分享，无需登录 |

官网导航栏提供“管理员登录”入口。“浏览官网”用于进入正式公开网站，“预览”用于管理员查看尚未发布的草稿。

## 二、公开官网

| 栏目 | 第一版内容与功能 |
| --- | --- |
| 首页 | 社团名称与定位、精选图片、最新动态、重点项目、荣誉成果、加入入口 |
| 关于我们 | 社团介绍、竞赛科研方向、指导老师、组织架构、联系方式 |
| 新闻与活动 | 新闻动态、活动预告、活动回顾；提供分类列表和详情页，展示活动时间、地点与状态 |
| 项目与成果 | 技术项目、竞赛获奖、科研成果；展示图片、项目介绍、参与成员、代码仓库和演示链接 |
| 师生风采 | 指导老师、社团骨干和成员介绍，支持按届别展示与归档 |
| 加入我们 | 招新对象、技术方向、加入方式、常见问题、外部报名链接或联系二维码 |

### 内容整理原则

- 可使用社团资源包中的基础素材。
- 活动新闻可从通信学院公众号搜集整理，保留来源与原文链接；图片适当标注来源和署名。
- 成员照片和个人介绍使用获准公开的资料。
- 暂缺资料在对应位置明确标注“待补充”，不编造人物、活动、奖项或项目成果。
- 已结束活动标记为“已结束”，避免访客误认为仍可报名。

## 三、管理员后台

管理员通过界面维护内容，无需修改代码。

| 功能 | 第一版要求 |
| --- | --- |
| 内容管理 | 新增、编辑新闻、活动、项目成果和师生资料 |
| 发布管理 | 保存草稿、预览、正式发布、下架、移入回收站及恢复 |
| 图片管理 | 上传封面、正文图片和活动照片，限制文件类型与大小 |
| 首页设置 | 调整展示图片、推荐项目和置顶动态 |
| 成员管理 | 维护师生资料、排序、隐藏及按届别归档 |
| 账号设置 | 修改密码、退出登录 |
| 操作记录 | 记录关键发布、修改、下架和权限变更的操作人及时间 |

### 角色与权限

| 角色 | 权限 |
| --- | --- |
| 管理员 | 维护网站内容、上传图片、调整首页展示、管理自己的密码 |
| 超级管理员 | 拥有管理员权限，并可创建或停用管理员账号、调整角色和重置密码 |

- 使用统一登录入口，由账号角色决定权限。
- 管理员使用各自的个人账号，方便追溯操作及人员交接。
- 初始超级管理员在部署时创建。
- 后台页面和服务端接口均需验证身份与权限；所有发布、修改、上传、删除及账号管理操作都必须经过服务端授权。
- 公开网站仅展示已发布内容，草稿预览仅对有权限的管理员开放。

## 四、视觉与使用体验

整体采用简洁、有科技感、适合学校社团的视觉风格，突出真实项目、活动照片和成果。

- 电脑端使用完整导航和内容卡片；手机端使用折叠菜单、单列内容和适合触屏的按钮。
- 官网与后台均适配手机，后台支持在手机上完成简单编辑。
- 文章和项目拥有独立地址，便于通过微信群、公众号等渠道分享。
- 图片支持压缩和延迟加载，活动照片支持点击放大。
- 保持文字对比清晰，为图片提供说明，主要入口支持键盘操作。
- 内容较少时先提供分类浏览，站内全文搜索可在后续版本加入。

## 五、技术结构与长期维护

项目采用“公开官网 + 管理后台 + 服务端 + 数据库”的完整结构。内容存入数据库，上传图片持久保存；具体技术栈在实施阶段确定。

### 安全与运行基础

- 密码使用安全的单向哈希保存，不以明文存储。
- 提供登录尝试限制和可靠的登录会话管理。
- 部署配置与代码分离，密码等敏感信息不写入前端或提交到代码仓库。
- 定期备份数据库及上传图片，并提供恢复方法。
- 配置页面标题、摘要及独立文章链接，支持基础搜索引擎适配。

### 可维护性

- 页面、业务逻辑和内容数据分开组织，方便增加栏目和功能。
- 提供本地运行、配置、上线部署及内容维护说明。
- 提供管理员账号交接、备份和恢复说明，方便不同届成员接手。

## 六、第一版验收标准

- [ ] 访客能够在电脑和手机上完整浏览官网各栏目。
- [ ] 新闻、活动和项目详情页可通过独立链接直接访问。
- [ ] 暂缺内容明确标注“待补充”。
- [ ] 管理员能够使用账号密码登录、修改密码及退出登录。
- [ ] 未登录或无权限的请求无法访问后台内容或执行管理操作。
- [ ] 管理员能够完成“创建草稿 → 上传图片 → 预览 → 发布 → 修改 → 下架”的完整流程。
- [ ] 草稿不出现在公开官网，发布及修改后的内容可及时在官网看到，下架内容不再公开展示。
- [ ] 内容可移入回收站并恢复。
- [ ] 超级管理员能够创建、停用管理员账号及重置密码。
- [ ] 内容与图片在服务重启后仍然保留。
- [ ] 具备可执行的本地运行、上线部署、备份恢复和日常维护说明。

## 七、后续迭代方向

以下功能暂不纳入第一版，可根据实际运营需求逐步增加：

- 普通用户注册、用户中心。
- 站内活动报名及报名管理。
- 站内全文搜索。
- 评论、论坛和成员交流。
- AI 问答。

第一版优先完成官网展示、内容更新和长期运行能力。
